# Vibe-Coding Policy Template: Group Input

This repository collects ideas for a **starting-point template that any organization can use to write its own vibe-coding policy**. It is not a code template. It gathers risks, ideas, examples, and wording on the topics a vibe-coding policy should cover.

**Status:** collecting input. Nothing here is final policy or official guidance.

## How to contribute

You need a free GitHub account. No coding or installation is required. Read [CONTRIBUTING.md](CONTRIBUTING.md) for step-by-step instructions.

**Everything you submit is public immediately and attributed to your GitHub account.** Do not include confidential information.
